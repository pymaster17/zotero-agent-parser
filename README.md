# Zotero Agent Parser

一个 Zotero 插件（Zotero 7 及以上），在添加新条目时自动把 PDF 交给 MinerU 解析成 Markdown 和 JSON，方便 agent 直接读取。解析产物放在 PDF 所在的附件目录里，通过 WebDAV 同步到其他电脑。

## 安装

```sh
./build.sh          # 生成 build/agent-parser-<版本>.xpi
```

在 Zotero 中打开「工具 → 插件」，点右上角齿轮选「从文件安装插件…」，选择生成的 `.xpi`。

## 解析服务

在「设置 → Agent Parser」中选择服务类型：

| 服务类型 | 适用场景 | 需要配置 |
|---|---|---|
| MinerU 云端精准解析 API（v4） | mineru.net 托管服务 | 在 mineru.net API 管理页申请的 Token |
| MinerU Tasks API | 本地 MinerU ≥ 4（`mineru-api`），或云端 `https://mineru.net/api` | 服务地址；如有，填写 API Key |

点「测试连接」可以检查配置是否可用。

**URL 直传（云端 v4）**：从白名单域名（默认 `arxiv.org`，可在设置中修改）保存的 PDF，插件会把附件记录的下载地址直接交给 MinerU，由服务端自己下载，省去上传时间。提交前插件会先请求一次该地址，确认返回的是 PDF 且大小与本地文件一致；不满足条件，或 MinerU 下载/解析失败时，自动改为上传本地文件。`full.md` 的 YAML 中 `parser_input` 记录了实际使用的方式。

## 触发方式

- **自动**：通过浏览器 Connector、拖入文件、「查找可用 PDF」等方式新增 PDF 附件时，插件会等文件下载完成，再加入解析队列。
- **手动**：在条目上右键，可选择「解析 PDF 为 Agent 可读格式」「强制重新解析 PDF」「显示解析结果」。
- **批量**：「工具 → 解析当前库中所有未解析的 PDF…」，或在右键菜单中一次选中多篇。首次安装后初始化整个库就用这个入口。

使用云端 v4 时，批量请求会按每批最多 50 篇提交：白名单域名的 PDF 合并成一个 URL 批次，其余合并成一个上传批次。文件逐个上传，服务端同时在解析已上传的文件，每篇解析完就立即保存。URL 方式失败的文件会自动改为上传重试。同一时间只运行一个批次，期间新添加的条目仍按单篇单独处理，不需要排在批次后面。每个批次结束时显示一条汇总通知，不会逐篇弹窗。

插件会把 PDF 的 SHA-256 写在 `full.md` 开头的 YAML 里。PDF 没有变化时，重复触发会直接跳过。队列保存在偏好设置中，Zotero 重启后会继续处理。

## 产物结构

```
<Zotero 数据目录>/storage/<附件键>/
├── 论文.pdf
└── parsed/                  # 文件夹名可在设置中修改
    ├── full.md              # Markdown 正文
    └── images/              # 图片、表格、公式截图（full.md 中用相对路径引用）
```

`full.md` 开头是一段 YAML，记录标题、作者、年份、DOI、标签、`zotero://` 链接、源 PDF 的 SHA-256 和解析时间；正文中公式为 LaTeX，表格为 HTML。解析服务返回的其他文件（JSON 中间结果、PDF 副本等）会被丢弃。

## 同步说明（重要）

- **WebDAV**：Zotero 的 WebDAV 文件同步会把整个附件目录打成 ZIP 上传，`parsed/` 也包含在内。但 Zotero 只根据主文件（PDF）的修改时间判断是否需要同步，所以解析完成后插件会做两件事：把附件标记为待上传，并更新 PDF 的修改时间。这样其他电脑即使已经有这个 PDF，也会重新下载带解析产物的 ZIP。这一行为可以在设置中关闭（「解析完成后标记附件待上传」）。
- **Zotero 自带存储（ZFS）**：PDF 是作为单个文件上传的，不会附带 `parsed/`，因此产物**不会**通过 ZFS 同步。
- 「跳过从同步下载的条目」默认开启：从同步收到的新条目不会在本机重复解析，由添加它的那台电脑负责解析并上传。
- 链接文件（linked file）默认不解析。开启后，产物写在 PDF 旁边的 `<文件名>.parsed/` 文件夹中，不经过 Zotero 同步。

## 注意

- API Token 和 Key 以明文保存在 Zotero 配置目录的 `prefs.js` 中。
- 云端 v4 API 对单个文件的限制是 200 MB / 200 页，超出时任务会失败并弹出通知。
- 上传给服务端的文件名统一为 `<附件键>.pdf`，以避开非 ASCII 文件名带来的问题；原文件名会记录在 `full.md` 开头的 YAML 中。
- `manifest.json` 中的 `update_url` 只是占位地址，发布前需要改成真实地址。
